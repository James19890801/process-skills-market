# 预凭证生成器 (Pre-Voucher Generator)

## 核心能力
接收企业原始凭证（银行流水/发票/合同/工资表等），按照中国会计准则自动生成预凭证台账Excel，包含：
- 智能科目匹配（用途驱动）
- 借贷平衡自校验
- 置信度分级标注
- 可追溯的原始数据保留

## 科目层级识别规则

### 科目代码结构
- **一级科目**：代码中无"."，如 `4401 工程施工`、`1002 银行存款`
- **二级科目**：代码中有1个"."，如 `4401.01 合同成本`、`6602.01 管理费用-租赁费`
- **三级科目**：代码中有2个"."，如 `4401.01.01 人工费`、`6602.01.01 办公室租金`

### 科目匹配优先级原则
1. **硬性规则**：所有凭证**只能使用2级及以下科目**，严禁使用一级科目
   - ✅ 正确：`4401.01 合同成本`（二级）
   - ✅ 正确：`6602.01 管理费用-租赁费`（二级）
   - ❌ 错误：`4401 工程施工`（一级，禁止使用）
   - ❌ 错误：`1002 银行存款`（一级，禁止使用）
   
2. **动态匹配原则**：Skill**不预设任何科目代码**，必须根据用户提供的科目表动态匹配
   - 读取用户提供的会计科目Excel文件
   - 根据用途关键词在科目名称中查找匹配
   - 返回匹配的完整科目代码+名称
   
3. **用途明确时**：优先匹配2-3级明细科目
4. **用途为空/不明确时**：先挂"往来"类科目，后缀根据业务自编
5. **劳务费硬性规则**：用途含"劳务/劳务工费/临时工/外包"时，在科目表中查找"劳务费"相关科目（如5401.01 劳务费），严禁用负债类科目（2202开头）

### 借贷记账法规则

**核心原则**：
- **资产类科目**（1开头）：增加记**借方**，减少记**贷方**
  - 例：收到款项 → 借：1002 银行存款（资产增加）
  - 例：支付款项 → 贷：1002 银行存款（资产减少）
  
- **负债类科目**（2开头）：增加记**贷方**，减少记**借方**
  - 例：欠款增加 → 贷：2202 应付账款（负债增加）
  - 例：偿还欠款 → 借：2202 应付账款（负债减少）
  
- **所有者权益类科目**（3开头）：增加记**贷方**，减少记**借方**

- **成本类科目**（4开头）：增加记**借方**，减少记**贷方**
  - 例：发生劳务费 → 借：4401.01 合同成本（成本增加）
  
- **损益类科目**：
  - 收入类（6开头）：增加记**贷方**，减少记**借方**
    - 例：确认收入 → 贷：6001 主营业务收入
  - 费用类（6开头）：增加记**借方**，减少记**贷方**
    - 例：发生手续费 → 借：6603 财务费用

**记忆口诀**：
- 资产/成本/费用：借增贷减
- 负债/权益/收入：贷增借减

**每笔凭证必须满足**：借方金额合计 = 贷方金额合计

## 五动作层处理流程

### 动作层0：材料整理与索引建立
**目标**：将原始材料标准化，建立可追溯索引

**执行步骤**：
1. 识别材料类型（银行流水/发票/合同/工资表）
2. 提取关键信息：
   - 银行流水：交易日期、金额、收付款人、用途、摘要
   - 发票：发票号码、开票日期、购销方、金额、税额、货物名称
   - 合同：合同编号、签订日期、合同双方、金额、付款条款
   - 工资表：员工姓名、部门、应发工资、社保、个税、实发工资
3. 生成材料索引表：
   ```
   | 序号 | 材料类型 | 文件名称 | 记录数 | 时间范围 | 备注 |
   ```
4. 建立时间轴（按业务发生日期排序）
5. 输出：材料整理报告（txt）

### 动作层1：逐笔业务解析
**目标**：按业务实质解析每笔交易

**执行步骤**：
1. 读取标准化材料（Excel/CSV）
2. 逐笔识别业务类型：
   - 支出类：劳务费/材料采购/租赁费/水电费/办公费/差旅费/招待费/运输费/设计费/检测费/银行手续费
   - 收入类：销售收款/预收款/利息收入/其他收入
   - 转账类：内部转账/银行间划转
3. 提取关键字段：日期、金额、收付款方、用途、摘要
4. 输出：业务解析清单

### 动作层2：智能科目匹配
**目标**：根据用途字段智能匹配会计科目

**匹配规则**：

#### 支出类（用途明确 → 在科目表中查找2-3级科目）
| 用途关键词 | 在科目表中查找的关键词 | 匹配逻辑 |
|------------|----------------------|----------|
| 劳务/劳务工费/人工费/临时工/外包 | "劳务费" | 查找包含"劳务费"的2级科目 |
| 工程/工程款/施工 | "工程" | 查找包含"工程"的2级科目，如无则用一级 |
| 材料/配件/物资 | "材料"或"原材料" | 查找包含"材料"的科目 |
| 租赁/租金/板房 | "租赁费" | 查找包含"租赁费"的2级科目 |
| 水电/电费/水费 | "水电费" | 查找包含"水电费"的2级科目 |
| 办公/办公用品 | "办公费" | 查找包含"办公费"的2级科目 |
| 差旅/出差 | "差旅费" | 查找包含"差旅费"的2级科目 |
| 招待/餐饮/餐费 | "招待费"或"业务招待费" | 查找包含"招待费"的2级科目 |
| 运输/物流/货运 | "运输费" | 查找包含"运输费"的2级科目 |
| 设计/图纸 | "设计费" | 查找包含"设计费"的2级科目 |
| 检测/检验 | "检测费" | 查找包含"检测费"的2级科目 |
| 银行手续费 | "手续费" | 查找包含"手续费"的2级科目 |

#### 用途不明确 → 往来科目
| 场景 | 在科目表中查找的关键词 | 匹配逻辑 |
|------|----------------------|----------|
| 用途="费用"+个人收款 | 个人姓名 | 查找1221开头的2级科目，如"1221.01 周月猛" |
| 用途="费用"+公司收款 | "其他应收款"或"往来" | 查找往来类科目 |
| 用途为空+个人收款 | 个人姓名 | 查找1221开头的2级科目 |
| 用途为空+公司收款 | "其他应收款"或"应收账款" | 查找往来类科目 |
| 用途未匹配到任何规则 | "其他应收款" | 查找往来类科目，后缀自编 |

#### 收入类
| 场景 | 在科目表中查找的关键词 | 匹配逻辑 |
|------|----------------------|----------|
| 收款（明确销售） | "银行存款"+"主营业务收入"或"预收账款" | 查找对应科目 |
| 收款（用途不明） | "银行存款"+"应收账款" | 查找对应科目 |
| 银行结息 | "银行存款"+"利息收入" | 查找包含"利息收入"的科目 |

#### 特殊处理
| 场景 | 识别规则 | 处理方式 |
|------|----------|----------|
| **银行结息（季度利息）** | 日期为3/6/9/12月20日 + 付款人为空 | 借：在科目表中查找"银行存款"，贷：在科目表中查找"利息收入"（如5603.02 利息收入） |
| 银行手续费 | 摘要含"手续费"或业务类型为"收费" | 借：在科目表中查找"手续费"（2级科目），贷：银行存款 |
| 红字/退款 | 金额为负数 | 金额取绝对值，借贷方向反转 |
| 跨行转账 | 付款人和收款人均为企业自身账户 | 借：目标银行账户，贷：源银行账户 |

### 动作层3：自校验
**目标**：验证凭证准确性

**校验规则**：
1. **借贷平衡**：每笔凭证 借方金额 = 贷方金额
2. **总额校验**：∑借方 = ∑贷方，差额为0
3. **置信度分布统计**：
   - 🟢 高置信度：用途明确，科目匹配准确
   - 🟡 中置信度：用途部分明确，需人工复核
   - 🔴 低置信度：用途不明，暂挂往来，必须人工确认
4. **异常检测**：
   - 金额异常（>平均值3倍标准差）
   - 日期异常（非工作日大额支出）
   - 收款人异常（频繁向同一个人账户付款）

### 动作层4：输出生成
**目标**：生成预凭证台账Excel

**输出格式**（12列）：
```
| 序号 | 日期 | 凭证编号 | 类型 | 摘要 | 借方科目 | 借方金额 | 贷方科目 | 贷方金额 | 置信度 | 备注 | 原始用途 |
```

**颜色标注**：
- 🟢 绿色背景：高置信度
- 🟡 黄色背景：中置信度
- 🔴 红色背景：低置信度

**输出文件**：
- 预凭证台账Excel（主文件）
- 材料整理报告txt（动作层0）
- 自校验报告txt（动作层3）

## 置信度分级标准

| 置信度 | 判断标准 | 颜色 | 处理建议 |
|--------|----------|------|----------|
| 高 | 用途明确，关键词匹配成功，科目为2-3级明细 | 绿色 | 可直接录入 |
| 中 | 用途部分明确，挂往来科目，需简要确认 | 黄色 | 建议复核后录入 |
| 低 | 用途为空/不明，暂挂往来，后缀为AI自编 | 红色 | 必须人工确认后录入 |
