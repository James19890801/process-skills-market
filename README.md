## 项目简介

AI流程Skills市场是一个基于业务流程管理体系构建的AI工具与智能体技能库，涵盖13个流程域，1200+ AI工具，帮助企业基于现有业务流程快速挖掘AI机会点，将最佳实践转化为可复用的AI能力。

## 技术栈

- 纯前端实现（HTML + CSS + JavaScript）
- 响应式设计，支持移动端
- Cloudflare Pages 部署

## 本地开发

```bash
# 克隆仓库
git clone https://github.com/James19890801/process-skills-market.git

# 进入目录
cd process-skills-market

# 本地预览（使用任意静态服务器）
npx serve .
```

## 部署

```bash
# 部署到 Cloudflare Pages
npx wrangler pages deploy . --project-name ai-process-skills
```
